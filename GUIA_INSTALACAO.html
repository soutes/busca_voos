busca_voos — guia de instalação

Monitor de passagens aéreas com alerta por e-mail e painel local. Escolha seu sistema e vá marcando cada etapa. Seu progresso fica salvo neste navegador.

0 de 0 etapas

1.Instalar o Python 3.10 ou mais novo

Baixe em python.org/downloads e, na primeira tela do instalador, marque “Add python.exe to PATH”. Depois abra o PowerShell e confira:

py -3 --version

Deve mostrar Python 3.10 ou superior.

2.Instalar o Google Chrome (para LATAM, GOL e Azul)

Baixe em google.com/chrome. Só é necessário se for usar as fontes dos sites das companhias; as outras funcionam sem ele.

3.Extrair a pasta vs_win

Extraia o ZIP que você recebeu (botão direito → Extrair tudo) em um lugar simples, por exemplo C:\busca_voos. Não rode de dentro do ZIP.

4.Instalar o programa

Jeito fácil: dê duplo clique em INSTALAR.bat e espere (alguns minutos, baixa ~150 MB). Ele cria o ambiente, instala tudo e gera config.yaml, .env e o banco.

Prefere fazer na mão? (PowerShell dentro da pasta) 
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[web]"
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe -m busca_voos.cli init

5.Configurar rotas e e-mail

Abra o config.yaml no Bloco de Notas e ajuste:

rotas:
  - origem: FLN                 # código IATA do aeroporto (ou cidade, ex.: RIO)
    destino: RIO
    janela_ida:   { de: 2026-12-20, ate: 2026-12-26 }
    janela_volta: { de: 2027-01-02, ate: 2027-01-06 }
    preco_maximo: 900           # avisa quando ida+volta ficar abaixo disso

fontes:
  google_flights: { ativo: true }
  latam:          { ativo: false }   # sites das companhias: precisam do Chrome
  gol:            { ativo: false }
  azul:           { ativo: false }

Ajuste também email.de (quem envia) e email.para (quem recebe).

6.Criar a senha de app do Gmail (para receber e-mails)

Recomendado: crie um Gmail só para o busca_voos (por exemplo meunome.buscavoos@gmail.com). Ele será o remetente dos alertas. Assim, se a senha de app vazar, sua conta pessoal fica protegida. Você continua recebendo os alertas no seu e-mail de sempre, que entra como destinatário.

Passo a passo

1) Crie o Gmail novo em accounts.google.com/signup (pule se já tiver um só para isso).
2) Ative a verificação em duas etapas nessa conta: abra myaccount.google.com/security → Verificação em duas etapas → Ativar e siga os passos (celular). Sem isso a opção de senha de app não aparece.
3) Abra as senhas de app: acesse myaccount.google.com/apppasswords. Se a página não abrir, vá em myaccount.google.com, digite Senhas de app na barra de busca e clique no resultado.
4) Em Nome do app, digite busca_voos e clique em Criar.
5) O Google mostra uma senha de 16 letras (em 4 blocos). Copie agora: ela aparece uma única vez. Os espaços podem ficar.
6) Deixe-a copiada. Você cola no painel na etapa 8, no campo Senha de aplicativo.

Use a senha de app, nunca a senha normal da conta. Não escreva a senha de app em nenhum arquivo nem envie para ninguém. Se perder, basta apagar e criar outra na mesma página. Contas com Proteção Avançada do Google ou de empresa/escola podem não oferecer essa opção.

7.Fazer um teste

Dê duplo clique em RODAR_CICLO.bat — faz uma busca agora. Para testar sem mandar e-mail, no PowerShell:

.\RODAR_CICLO.bat --sem-email

Testar um site de companhia (abre uma janela do Chrome)

.\.venv\Scripts\python.exe -m busca_voos.cli testar latam --origem GRU --destino GIG --ida 2026-12-10

8.Abrir o painel e cadastrar a senha do e-mail

Duplo clique em ABRIR_PAINEL.bat. O painel abre no navegador (endereço http://localhost:8787). Depois:

1) Clique na aba Gestão & configurações.
2) Em Notificações por e-mail, confira os e-mails de envio e de recebimento e cole a senha de app no campo Senha de aplicativo.
3) Clique em Salvar configurações.
4) Clique no botão de teste de e-mail e veja se a mensagem chega.

A senha é guardada criptografada neste computador (arquivos dados.sqlite3 e .segredo.key). Não envie esses arquivos para ninguém e faça backup do .segredo.key: sem ele, a senha salva não abre e você precisa cadastrá-la de novo.

9.Deixar rodando sozinho

Dê duplo clique em RODAR_DAEMON.bat e deixe a janela aberta (busca de tempos em tempos). Para iniciar sozinho com o Windows:

Agendador de Tarefas → Criar Tarefa Básica → disparador Ao fazer logon → ação Iniciar um programa apontando para RODAR_DAEMON.bat.

As fontes LATAM, GOL e Azul abrem uma janela do Chrome a cada consulta. Se isso incomodar, deixe-as desmarcadas.

10.Atualizar no futuro

Quando receber uma versão nova, substitua os arquivos mantendo config.yaml, dados.sqlite3 e .segredo.key, e dê duplo clique em atualizar.bat.

Problemas comuns (Windows)
SintomaO que fazer
“Não encontrei o Python”Reinstale o Python marcando Add python.exe to PATH e rode o INSTALAR.bat de novo.
Fonte “bloqueada”O site barrou seu IP. Espere algumas horas e reduza a frequência das buscas.
Chrome não abre (LATAM/GOL/Azul)Confirme que o Google Chrome está instalado (etapa 2).

sudo apt update
sudo apt install -y python3 python3-venv python3-pip
python3 --version

Precisa ser Python 3.10 ou superior.

2.Instalar o Google Chrome (para LATAM, GOL e Azul)

wget -q https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo apt install -y ./google-chrome-stable_current_amd64.deb

Só é necessário para as fontes dos sites das companhias. As demais funcionam sem ele.

3.Colocar a pasta vs_linux no computador

Extraia o que recebeu e entre na pasta (ajuste o caminho):

cd ~/vs_linux

4.Instalar o programa

Jeito fácil (cria o ambiente, instala tudo, gera config.yaml, .env e o banco):

bash instalar.sh
Prefere fazer na mão?

.venv/bin/pip install -e ".[web]"
.venv/bin/playwright install chromium
# se o Chromium reclamar de bibliotecas do sistema:
sudo .venv/bin/playwright install-deps chromium
.venv/bin/busca-voos init

9.Deixar rodando sozinho

Opção A — no seu desktop, num terminal aberto

.venv/bin/busca-voos run

Opção B — em segundo plano, sem janelas do Chrome na tela (usa tela virtual)

sudo apt install -y xvfb
xvfb-run -a .venv/bin/busca-voos run

Opção C — serviço que inicia com o computador (systemd)

sudo cp systemd/busca-voos.service /etc/systemd/system/
sudo nano /etc/systemd/system/busca-voos.service   # ajuste User e caminhos
sudo systemctl daemon-reload
sudo systemctl enable --now busca-voos
journalctl -u busca-voos -f
As fontes LATAM, GOL e Azul abrem o Chrome com janela. Num serviço systemd (sem tela) coloque /usr/bin/xvfb-run -a no começo do ExecStart, ou deixe essas fontes desmarcadas.
